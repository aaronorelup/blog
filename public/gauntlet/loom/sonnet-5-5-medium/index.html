LOOM Studio

A tiny language for woven cloth. Write a loom program on the left, watch it become fabric on the right.
New here? What am I looking at?

Cloth is made of warp threads (they run up and down, fixed on the loom) and a weft thread that the shuttle passes across, one row (pick) at a time. Each warp thread is tied to a shaft; on every pick some shafts are lifted. A lifted thread shows its own color in that row, an unlifted one lets the weft color show instead.

A LOOM program sets up the threads (warp, thread) and then throws picks (pick c 12: weft color c, lift shafts 1 and 2). Press Run, then try the Loom tab to watch it weave, or the Debugger to step through it. The Gallery has ready-made cloth; the Guide lists every command.
