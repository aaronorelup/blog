Browser timing check

A measuring page, not an app. It repeats two tests that were run on a cloud computer without a sound card or GPU, so the numbers from your own browser can be put next to them. Keep this tab in front while it runs. Nothing is sent anywhere: when it finishes, copy the box at the bottom and paste it back.

1. Metronome timing

Four ways of making a 120 BPM click: (a) clicks scheduled ahead on the audio clock by a 25 ms timer loop, (b) a click started from each setInterval tick, (c) Tone.js Transport, (d) clicks written by an AudioWorklet. Each runs idle and then with the page's main thread kept busy (100 ms blocks). The output is recorded inside the browser and every click is found to the sample. Clicks are silent unless you tick "audible".

2. In-browser model: Basic Pitch

Spotify's Basic Pitch (TensorFlow.js, loaded from the jsDelivr CDN, about 1 MB of model files) transcribes a 30 s test melody that this page synthesizes itself (the 62 notes of the shared clip S1, "Ode to Joy"), first on the WebGL backend (your GPU), then on the plain CPU backend. It prints the time and how many notes it found at the right time and pitch.

3. The same model in ONNX Runtime Web: WebAssembly and WebGPU

The ONNX file of the same Basic Pitch model (230 KB, from Spotify's basic-pitch repository on GitHub) in ONNX Runtime Web 1.31.1 from jsDelivr, on the same test melody: once on WebAssembly (CPU) and once on WebGPU (your GPU), if Chrome offers a WebGPU adapter. The WebGPU part could not be tried on the cloud box (no GPU there).
